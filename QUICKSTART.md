# 🚀 TagForge - Quick Start Guide

## Launch the Application

### Option 1: Direct Browser (Easiest)
Simply double-click `index.html` to open it in your default browser.

### Option 2: Local Server (Recommended)

**Using Python:**
```bash
cd c:\AI_ML_Projects\GeoVide
python -m http.server 8000
```
Then open: `http://localhost:8000`

**Using Node.js:**
```bash
cd c:\AI_ML_Projects\GeoVide
npx serve
```

**Using VS Code:**
- Install "Live Server" extension
- Right-click `index.html` → "Open with Live Server"

## 🎯 Quick Tutorial (2 Minutes)

### Step 1: Upload a Photo
1. Click the upload area or drag & drop any photo
2. If your photo has GPS data, it will auto-populate

### Step 2: Set Location
- **Option A**: Click anywhere on the map
- **Option B**: Click the 🎯 button for your current location
- **Option C**: Manually enter latitude/longitude

### Step 3: Customize
- Edit the address/place name
- Adjust date & time
- Add a custom caption (optional)

### Step 4: Download
- Preview your photo with the overlay
- Click "Download Photo" to save

## 🎨 Try These Features

✅ **Toggle Theme**: Click sun/moon icon (top-right)  
✅ **Live Preview**: Watch overlay update in real-time  
✅ **Map Interaction**: Zoom, pan, and click to set pins  
✅ **Reset**: Clear everything and start fresh  

## 🔥 Pro Tips

- Photos with EXIF data auto-populate location
- Address is fetched automatically when you click the map
- Use "Update Map Location" after manually entering coordinates
- The overlay format is: "Location • Date Time"
- Downloaded photos are high-quality JPEGs

## ⚡ Keyboard Shortcuts

- `Tab` - Navigate between fields
- `Enter` - Submit forms
- `Esc` - Close dialogs (if any)

## 🐛 Troubleshooting

**Map not loading?**
- Check your internet connection
- Refresh the page

**Location button not working?**
- Allow location permissions in your browser
- Ensure you're using HTTPS or localhost

**EXIF data not extracting?**
- Some photos don't have GPS data
- Try a photo taken with a smartphone

**Download not working?**
- Make sure you've uploaded a photo first
- Check browser download permissions
